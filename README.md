# Valier Corp GTNH Build Atlas

Interactive city plans, exterior designs, block palettes and staged assembly guides for an original Serenity City adaptation in GTNH 2.9.

Website: https://eggonomicon.github.io/valier-build-atlas/

Build planning: https://eggonomicon.github.io/valier-build-atlas/#operations/01-01

The planning section supplies all81 department programs and324 activity zones,81 model-derived operations drawings, and32 proposed machine cells across Steam Works, LV factory, ore processing, chemistry and circuits. It also contains the unchanged12-block road/gallery section, infrastructure-first startup sequence,31 installed singleblock machine identities and downloadable planning models/CSVs. Source shells and the65-square HQ reservation are unchanged.

Zone outlines allocate activities rather than construct partition walls. Only the five initial singleblock layouts have checked equipment positions and operator routes. Multiblocks, utilities, demand balance, recipes, runtime configuration and game tests remain open.

Click city plots or browse the library. Use scroll/zoom presets, drag pan and full screen. Block layers report model-local/city coordinates, material metadata and construction stages. Planning tools do not edit a game world.

All coordinates remain local: northwest origin, +X east, +Z south. Civil Y0 is the future walkable surface S, currently unassigned. The intended PDIM does not yet exist.

These are design studies and assembly instructions, not game-tested functional factories. Installed block identity evidence is separate from unverified recipes, machine formation, utilities, collision and import results. AI references are labeled concepts rather than measured blueprints.

Only reviewed publication assets are included. Original recovery archives, source chat, raw installed-game evidence, credentials and game worlds are excluded.

GitHub Pages serves the main branch root. `.nojekyll` preserves the static assets. No build service or runtime secret is needed.
